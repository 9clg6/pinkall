# Afficher les appels récents

**ID:** STORY-003  
**Epic:** Home  
**Priority:** Must Have  
**Story Points:** 5

## User Story

As a founder, I want to see recent calls and start a new simulated call so that I immediately understand the product.

## Acceptance Criteria

- [x] Le screen respecte la triade State/ViewModel/Screen.
- [x] Le chargement, l’erreur, la donnée et la liste vide sont rendus.
- [x] Les cartes affichent interlocuteur, entreprise, date, durée et état de débrief.
- [x] Le CTA principal ouvre l’appel simulé.
- [x] Le layout s’adapte au mobile et à une fenêtre macOS large.
