# Lire le débrief d’un appel

**ID:** STORY-005  
**Epic:** Debrief  
**Priority:** Must Have  
**Story Points:** 5

## User Story

As a founder, I want a transcript, a concise follow-up and one coaching action so that the next call is easier to improve.

## Acceptance Criteria

- [x] Le screen respecte la triade State/ViewModel/Screen.
- [x] La transcription distingue clairement « Moi » et « Prospect » avec des timestamps.
- [x] Le résumé, les engagements et le follow-up sont visibles.
- [x] Une seule amélioration prioritaire est reliée à un passage précis.
- [x] La méthode/source est présentée comme illustrative, sans prétention d’IA réelle.
