# Simuler un appel

**ID:** STORY-004  
**Epic:** Call  
**Priority:** Must Have  
**Story Points:** 5

## User Story

As a founder, I want a believable call screen so that I can judge whether Pinkall could replace my phone workflow.

## Acceptance Criteria

- [x] Le screen respecte la triade State/ViewModel/Screen.
- [x] Le timer, la waveform et les contrôles mute/speaker/end sont interactifs.
- [x] L’interface indique explicitement qu’il s’agit d’une simulation locale.
- [x] Terminer l’appel ouvre le débrief associé.
- [x] Les contrôles tactiles font au moins 44 × 44 dp.
